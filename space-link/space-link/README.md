# SPACE-LINK Mission Control

Menu-driven C program demonstrating three data structures:

1. **Satellite Registry** - linked list (add, display, search, delete)
2. **Emergency Signals** - priority queue using a sorted array (highest severity first)
3. **Communication Network** - graph (adjacency matrix) + BFS for the route with the fewest links

## Compile and run

```
gcc space_network.c -o space_network
./space_network
```

On Windows PowerShell use `.\space_network`.
